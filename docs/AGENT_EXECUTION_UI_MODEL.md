# Agent-operated execution model

The Mission Console is an observation and evidence surface, not a manual trading terminal.

## Responsibilities

- The agent performs its own execution preparation and pre-execution checks.
- The user's Altana session defines the execution authority already granted to the agent.
- AgentMarket displays the verified authorization and agent-reported execution scope.
- AgentMarket independently observes transaction/receipt evidence after execution.
- ERC-8183 remains the job and commerce lifecycle.

## Mission Console rule

Do not require the user to enter router, token, amount, fee, or minimum-out values, and do not require the user to press a preflight or execute button for the agent to perform its hired task.

The console may show these facts when independently available, but they are evidence/observations rather than user-operated controls.

## Grid

Grid remains the first-party BNB Agent Studio / ERC-8183 test agent. Its execution service and Altana path remain agent-side. This UI change does not remove or replace Grid's execution infrastructure.
